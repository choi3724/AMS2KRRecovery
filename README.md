# AMS2 한국어 패치 완전 삭제 0.1

기존에 배포한 AMS2 한글패치를 제거하고 **Steam에서 현재 게임 버전의 원본을 복구**하는 Windows 도구입니다. 한글패치의 버전 번호나 설치 기록 형식으로 삭제를 제한하지 않습니다. 구버전 원본 파일을 최신 게임 위에 덮어쓰지 않습니다.

[0.1 다운로드](https://github.com/choi3724/AMS2KRRecovery/releases/tag/v0.1)

## 사용 방법

1. AMS2와 한글 런처·설치 프로그램을 종료합니다. Content Manager 사용자는 적용한 모드를 먼저 비활성화합니다.
2. `AMS2KRRecovery-0.1.exe`를 실행하고 게임 폴더를 확인합니다.
3. **1. 완전 삭제 및 복구 시작**을 누릅니다. 대상 파일을 백업한 다음 제거하고 Steam 무결성 검사를 요청합니다.
4. Steam의 검사와 다운로드가 끝날 때까지 기다립니다. Steam 창이 열리지 않으면 **Steam 복구 다시 요청** 또는 Steam → AMS2 속성 → 설치된 파일 → 게임 파일 무결성 검사를 이용합니다.
5. **2. 원본 복구 완료 확인**을 누릅니다. 현재 Steam 원본 목록과 파일 크기·해시가 일치해야 완료로 표시합니다.

Steam 복구 요청은 복구 완료가 아닙니다. 완료 확인 전에는 게임을 실행하지 마세요. Steam 실행 옵션에 직접 추가한 `-lang=Korean -looseloadtext`가 있다면 제거해주세요. Steam 계정 설정은 자동 변경하지 않습니다.

## 삭제·보존 범위

- 초기 비공개 배포부터 Open Beta 0.88.1까지 확보한 전체 배포 자료에서 합친 678개 관리 경로가 대상입니다. 번역, 기본 폰트와 추가 폰트, 메뉴, 수정 아카이브, 일반·VR 런처를 포함합니다.
- 손상되거나 없는 설치 기록에도 같은 목록을 사용합니다. 버전별 설치 파일 수나 기존 백업을 신뢰해 원본을 덮어쓰지 않습니다.
- 한글판 바로가기는 연결 대상이 해당 게임의 한글 런처인지 확인한 후 정리합니다. 표준 바탕 화면·시작 메뉴·작업 표시줄 밖의 사용자 지정 바로가기는 보존합니다.
- 현재 파일, 설치 상태, 중단된 업그레이드 기록을 백업합니다. 세이브·리플레이·기존 안전 백업과 목록 밖의 다른 파일은 보존합니다.
- 같은 파일을 수정한 다른 모드도 Steam 원본으로 돌아갑니다. CM 활성 모드가 있거나 기록을 읽을 수 없으면 파일 변경 전에 중단합니다.

백업과 로그: `<게임 폴더>\Backup\AMS2KRRecovery\<작업 ID>\`

실패하면 이번 작업 전 상태로 되돌립니다. 프로세스 강제 종료 후 다시 실행하면 중단 기록을 확인합니다. 이후 다른 프로그램이 변경한 파일이나 업데이트된 게임에는 이전 파일을 강제로 덮어쓰지 않으며, 실패 기록과 백업을 보존합니다. 백업까지 지워 복구 가능성을 없애는 프로그램은 아닙니다.

## 지원 조건과 한계

- Steam판 AMS2, Windows, .NET Framework 4.6 이상. 관리자 권한과 Steam 원본 다운로드가 필요할 수 있습니다.
- 게임 빌드 허용 목록이 없습니다. 복구는 Steam이 선택한 현재 브랜치/버전의 원본을 사용합니다.
- Steam 원본 목록이 없거나 읽을 수 없으면 완료를 선언하지 않습니다. Steam 무결성 검사를 끝낸 후 다시 확인합니다.
- 이후 한글패치가 **새로운 경로**를 추가하면 관리 목록 갱신이 필요합니다. 알 수 없는 파일을 이름 추측으로 지우지는 않습니다.
- 자동 테스트는 격리된 복사본에서 수행했습니다. 실제 설치된 게임 삭제, Steam 다운로드 전 과정, 사용자 PC에서의 영문 화면은 이번 배포 과정에서 시험하지 않았습니다.

## 빌드·검증

Python 3 및 Windows의 .NET Framework 컴파일러를 사용합니다. 게임 원본 바이너리를 저장소나 실행파일에 포함하지 않습니다.

```powershell
python tools/build.py
python tools/test.py
python tools/audit_catalog.py <과거_배포_폴더>
```

산출물: `build/AMS2KRRecovery-0.1.exe`. 테스트용 `RecoveryCheck.exe`는 공개 실행파일에 포함하지 않습니다. 공개 실행파일에는 테스트용 명령과 실패 주입 기능이 없습니다.

검증 근거는 `evidence/test-result.json`, `evidence/catalog-audit.json`에 있습니다. 구버전 테스트는 역사적인 파일 목록과 손상/누락 기록을 구성한 복사본이며, 모든 과거 설치 프로그램을 실제로 실행했다는 의미는 아닙니다.
